# Audio files

This folder is intentionally empty: the catalog contains music metadata, not licensed audio recordings. Add only audio that you own or are licensed to distribute.

To connect a file, place it here and set that song's `file_path` in the `songs` table, for example `/audio/my-royalty-free-track.mp3`.

The player also accepts an `audio_url` or `audio_file` field. Tracks without a configured audio source show a translated message in the player.
